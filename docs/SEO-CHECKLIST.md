# SEO Checklist

## On-Page SEO
- [ ] Unique, descriptive `<title>` tags for all pages (Home, Services, Locality pages).
- [ ] Unique `<meta name="description">` for all pages.
- [ ] Single `<h1>` per page, logically structured `<h2>` and `<h3>` tags.
- [ ] Descriptive `alt` attributes on all images.
- [ ] Internal linking between locality pages and service pages.
- [ ] Canonical URLs set for every page to avoid duplicate content issues.
- [ ] Open Graph tags for better social sharing.

## Technical SEO
- [ ] `robots.txt` is present and correctly allows crawling.
- [ ] `sitemap.xml` is dynamically generated or updated and includes only canonical, indexable pages.
- [ ] Fast loading times (images optimized, lazy loading applied below the fold).
- [ ] Mobile-friendly and responsive layout.
- [ ] Custom 404 error page.

## Structured Data
- [ ] JSON-LD `LocalBusiness` (or `Plumber`) schema on the homepage.
- [ ] JSON-LD `BreadcrumbList` on inner pages.
- [ ] JSON-LD `Service` schema on specific service pages.

## Off-Page & Local
- [ ] Claim and verify Google Business Profile.
- [ ] Ensure NAP (Name, Address, Phone) consistency across the web.
- [ ] Register with Google Search Console and submit the sitemap once live.
