# Sushanth Plumbing Services

A modern, responsive business website for Sushanth Plumbing Services & Renovation & Grouting, Hyderabad. Built with React and Supabase, featuring plumbing service pages, renovation and grouting services, customer enquiry forms, WhatsApp integration, SEO optimization, and an admin dashboard for website management.

## Project Structure
- `frontend/`: React + Vite frontend application.
- `backend/`: Serverless Vercel API functions.
- `supabase/`: Database schema and migrations.
- `docs/`: Setup and deployment guides.
